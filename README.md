# AJ STUDIO

Simulador interativo da AJ STUDIO — Branding & Web Design.

O cliente digita o nome do seu estabelecimento, escolhe o segmento (barbearia, restaurante, pet shop, loja de roupas, clínica, oficina, salão, academia, padaria, imobiliária, advocacia, serviços em geral) e vê, em um celular interativo, um esboço do primeiro site do seu negócio — com agendamento ou pedido de teste, galeria, contato e botão de WhatsApp.

Slogan: **Um novo olhar transforma seu negócio**

## Como abrir

É uma página única (`index.html`) em React, sem build nem dependências para instalar. Basta abrir o arquivo em um navegador, ou publicar a pasta em qualquer hospedagem de site estático (GitHub Pages, Netlify, Vercel etc.).

## Estrutura

- `index.html` — a página inteira (estilos, componentes React e dados dos segmentos).
- `img/` — fotos de cada segmento: `<segmento>.jpg` (topo), `<segmento>-2.jpg` (ambiente) e `<segmento>-3.jpg` (detalhe).
